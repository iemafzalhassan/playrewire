# Roadmap

PlayRewire is in the **design phase**. This roadmap follows the phases in the [design doc](docs/superpowers/specs/2026-10-21-playrewire-design.md#11-phasing-call). Dates come once the Phase 0 spikes are done.

## Phase 0: Spikes 🧪 *(next)*
Prove the risky parts before building on them.
- [ ] Bevy (WASM/WebGPU) inside a Tauri v2 webview: frame rate on a mid-range Android phone and an iPhone
- [ ] Yaegi compiled to WASM as the browser and mobile Go lab
- [ ] Linux `lab-runner`: real Go toolchain in namespaces + seccomp + Landlock with resource limits
- [ ] Real-time ink-outline and watercolor shader prototype

## Phase 1: First playable 🎮
- [ ] Desktop (Linux first) and web builds
- [ ] Silicon Quarter and the Go Academy basics
- [ ] See → Type → Drill → Use chunk player
- [ ] Local progress (SQLite), XP and streaks
- [ ] Lesson-pack format v1

## Phase 2: Online 🌐
- [ ] Accounts, `session-guard` (one live session, activity heartbeats)
- [ ] Offline-first sync, `progress`, `practice-scheduler`
- [ ] `notification` service
- [ ] Personal skill map and "what broke" analytics
- [ ] Helm chart for self-hosting

## Phase 3: Squads 👥
- [ ] Friends and parties
- [ ] Squad heists with realtime state relay
- [ ] Peer verification of solutions
- [ ] Leaderboards

## Phase 4: Certified 🏅
- [ ] Guarded exam mode
- [ ] Open Badges 3.0 issuer and verify page
- [ ] LinkedIn and Credly sharing

## Phase 5: Everywhere 📦
- [ ] Android, iOS, macOS and Windows releases
- [ ] Official packages: deb, rpm, AUR, Flatpak, AppImage, msi, winget, dmg, Homebrew
- [ ] All ten districts complete

## Phase 6: Grow 🌱
- [ ] Second programming language
- [ ] Kids' mode
- [ ] Engineer fast-track and placement challenges
- [ ] CNCF Landscape submission and public launch
