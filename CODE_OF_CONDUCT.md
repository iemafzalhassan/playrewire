# Code of Conduct

PlayRewire follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

We're building a place where people who are new, nervous, or "not technical" feel welcome. Be patient, assume good intent, and remember that every expert was once a beginner.

## Reporting

To report a Code of Conduct violation, email the maintainers at **iemafzalhassan@gmail.com**. Reports are handled confidentially.

If the issue involves a maintainer, or you aren't satisfied with the response, you can contact the CNCF Code of Conduct Committee at **conduct@cncf.io**.
